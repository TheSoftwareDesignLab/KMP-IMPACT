# Getting started

Three short pages to get the analyzer running on your machine:

1. **[Requirements](requirements.md)** — JDK 21, Gradle 8.7+, Android SDK, Python 3.10+.
2. **[Installation](installation.md)** — `pip install -e ".[dev]"` and the test smoke check.
3. **[Quickstart](quickstart.md)** — first end-to-end analysis on a sample KMP project.

If you only want to wire the tool into GitHub Actions, skip directly to [Usage → GitHub Action](../usage/github-action.md).
